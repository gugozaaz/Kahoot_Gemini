R: Rules
	Player ไม่จำเป็นต้องสมัครสมาชิกเพื่อเข้าเล่นเกม
	ระบบคำนวณคะแนนจาก 2 ปัจจัยคือ "ความถูกต้อง" และ "ความเร็ว" (ตอบถูกแต่ช้าจะได้คะแนนลดหลั่นลงไป)
	หากหมดเวลา (Time limit) และ Player ยังไม่ได้กดตอบ ระบบจะบันทึกว่าตอบผิดและได้ 0 คะแนน
	Host มีสิทธิ์เตะ (Kick) Player ที่ตั้งชื่อเล่นไม่เหมาะสมออกจากหน้ารอก่อนเริ่มเกมได้เสมอ
	

ผู้ใช้งานมี 2 ฝ่าย คือ ครูและนักเรียน 

การทำงานของครู คือสร้างสื่อการสอน ในรูปแบบ gamification โดยที่ขั้นตอนการสร้างจะเป็นการสร้าง slideshow คล้าย powerpoint 
จากนั้นนำสื่อการสอนนี้เปิดเป็น host game server ตอบคำถาม ให้นักเรียน join server ของครูเพื่อเข้ามาตอบคำถามได้

การทำงานของนักเรียนคือ join server ของครู ด้วยวิธีการกรอกเลข game pin หรือ redirect ด้วยการ scan QR code บนหน้าจอของครู
จากนั้นตอบคำถาม ตาม slideshow ที่ครูเป็นผู้สร้างขึ้น และจะมีการแข่งขันกันเองด้วยระบบคะแนน ที่ผู้ตอบถูกจะได้คะแนน และผู้ที่ตอบถูกได้เร็วกว่าจะได้คะแนนที่สูงกว่า

โดยหน้าจอหลักของระบบ เป็นหน้าจอเปล่าๆ background สีเหลืองสด ที่แสดงโลโก้ Kamooy! 
ตรงกลางหน้าจอเป็น textbox ที่รับค่าตัวเลข game pin จำนวน 6 หลัก เพื่อเข้าร่วม game server 
ด้านบนขวา เป็น button เข้าสู่ระบบ เพื่อไปหน้าจอ login และ register เข้าสู่ระบบของครู

หน้าจอของครู ต้องมีการตรวจสอบยืนยัน user ครู โดยในระหว่างช่วงทดสอบ ให้ bypass การ login ไปยัง หน้าจอหลัก 'จัดการสื่อการสอน' ได้เลย 
หน้าจอหลัก 'จัดการสื่อการสอน' เป็นหน้าจอที่เป็น showcase สิ่งที่แสดงคือ slideshow ของ user ครูที่เคยสร้างเอาไว้ และด้านขวาบน มี button + สร้างสื่อใหม่ และสำหรับ slide ที่สร้างไว้แล้ว ให้มี 3 button ให้เลือกคือ เล่น , แก้ไข , ลบ
หน้าจอ 'สร้างสื่อใหม่' เป็นหน้าจอที่ใช้ในการออกแบบสื่อการสอน แบ่งส่วนหน้าจอเป็น 3 ส่วนคล้ายการออกแบบ powerpoint ดังนี้
ส่วนซ้าย เป็น list ของ slide และมีปุ่ม + เพิ่มเพิ่ม slide และ silde ที่ถูกสร้างไว้แล้วต้องสามารถสลับที่ขึ้นหรือลงได้ ต้องสามารถ duplicate slide ได้ และ delete slide ได้
ส่วนกลาง เป็น หน้าจอ preview slide ซึ่งจะใช้ส่วนประกอบจากส่วนขวามาประกอบกัน โดย default position การจัดวาง คือ 
- คำถาม อยู่ส่วนบนของ slide 
- ภาพประกอบ อยู่ส่วนกลางของหน้าจอ โดยระบบจะต้อง resize ภาพให้อยู่ในกรอบได้พอดี หากเลือก checkbox ให้แสดงภาพเต็มจอ ภาพจะแสดงเป็น background ที่ขยายเต็มจอแทน และลบกรอบรูปออกไป 
- คำตอบ อยู่ส่วนล่างของ slide 
ส่วนขวา เป็น รายละเอียดของ slide ซึ่งสามารถกำหนดค่าได้ดังนี้
- คำถาม ใส่ข้อความของคำถาม 
- คำตอบ ใส่ข้อความของคำตอบ เป็น list ที่สามารถกด button + ที่ด้านบนสุดของ list เพื่อเพิ่มคำตอบ หรือกด button - ที่ด้านหลังของคำตอบนั้นๆ เพื่อลบคำตอบ จำนวนคำตอบที่สามารถตั้งค่าได้คือ 2 ถึง 6 โดยจำนวน default คือ 4 และที่ด้านหน้าของแต่ละ list คำตอบให้แสดง checkbox เพื่อระบุว่าคำตอบนั้นคือคำตอบที่ถูกต้องด้วย โดยที่ในแต่ละคำถามสามารถมีคำตอบที่ถูกต้องได้มากกว่า 1 คำตอบ
- ภาพประกอบ สามารถ upload ภาพ เพื่อใช้ในการแสดงเป็นภาพประกอบคำถามได้ และมี checkbox เพื่อให้เลือกแสดงภาพเต็มจอได้
- ตั้งค่าเวลา กำหนดระยะเวลาสำหรับ countdown ในการตอบคำถามข้อนั้นๆ โดยมี list ให้เลือกคือ 5 วินาที , 10 วินาที , 15 วินาที , 20 วินาที , 30 วินาที , 45 วินาที , 60 วินาที โดยจำนวน default คือ 30 วินาที
- ตั้งค่าการให้คะแนน เป็นการกำหนดวิธีการให้คะแนน โดยมี list ให้เลือกคือ ไม่มีคะแนน , คะแนนมาตรฐาน (1 เท่า) , คะแนนสองเท่า , คะแนนสามเท่า โดยจำนวน default คือ คะแนนมาตรฐาน
จากหน้าจอ 'จัดการสื่อการสอน' เมื่อกด button 'เล่น' ภายใต้ slide ที่สร้างไว้แล้ว จะเข้าสู่หน้าจอ 'ห้องเล่นเกม' และเริ่ม process ส่วนการเล่นเกม 

การทำงานของหน้าจอ 'เล่นเกม' จะแบ่งการทำงานออกเป็น 2 ฝั่ง คือหน้าจอเล่นเกมของครู และหน้าจอเล่นเกมของนักเรียน โดยมีลำดับการทำงานดังนี้
1. การสร้างห้องเล่นเกม
1.1 หน้าจอเล่นเกมของครู จะเป็นหน้า lobby ที่เปิดรับนักเรียนที่จะเข้าเล่นเกม 
- ส่วนบนของหน้าจอ แสดงเลข PIN ของเกม และ QR code เพื่อให้นักเรียน scan 
- ส่วนกลางของหน้าจอ แสดงรายชื่อของนักเรียน ที่เข้าสู่ lobby มาแล้ว
- ส่วนล่างของหน้าจอ แสดงปุ่ม 'เริ่มเกม'
1.2 หน้าจอเล่นเกมของนักเรียน โดยนักเรียนมีวิธีเข้าสู่ห้องเล่นเกม ได้ 2 วิธีคือ เข้า หน้าจอหลักของระบบ (Kamooy.it) แล้วกรอกเลข PIN ที่แสดงบนหน้าจอเล่นเกมของครู หรือ scan QR code ที่ปรากฏบนหน้าจอเล่นเกมของครู
